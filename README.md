# Cloud-Based Data Analytics Dashboard

## Overview

Cloud-Based Data Analytics Dashboard is a full-stack analytics platform developed using React.js, Node.js, and Express.js. The project provides real-time analytics visualization, transaction monitoring, and interactive charts.

## Features

- Real-time analytics dashboard
- Revenue visualization charts
- Transaction monitoring table
- Responsive UI
- REST API integration
- Error handling
- Loading states
- Modular architecture
- Cloud-ready design

## Technologies Used

### Frontend
- React.js
- Tailwind CSS
- Axios
- Recharts

### Backend
- Node.js
- Express.js
- CORS

### Future AWS Integration
- AWS Kinesis
- AWS Lambda
- Amazon Redshift
- AWS Auto Scaling

## Installation

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```

## Environment Variables

Create `.env` inside frontend:

```env
VITE_API_URL=https://aws-real-time-analytics-dashboard-backend-2sxk.onrender.com
```
