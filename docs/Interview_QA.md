
# Interview Questions and Answers

## What is your project?

Cloud-Based Data Analytics Dashboard is a full-stack web application that provides real-time analytics visualization using React.js and Node.js.

## Why did you build this project?

To provide a scalable analytics platform that can visualize business data and support future AWS integration.

## Technologies Used

Frontend:
- React.js
- Tailwind CSS
- Axios
- Recharts

Backend:
- Node.js
- Express.js

Cloud:
- AWS Kinesis (Planned)
- AWS Lambda (Planned)
- Amazon Redshift (Planned)

## What features did you implement?

- Real-time analytics dashboard
- Dynamic transactions table
- Interactive charts
- REST APIs
- Environment variables
- Error handling
- Loading states

## How does data flow in your project?

Frontend sends API requests to Express backend. The backend processes requests and returns analytics data which is displayed on the dashboard.
