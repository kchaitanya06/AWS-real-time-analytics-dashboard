
# Resume Project Description

Cloud-Based Data Analytics Dashboard

Developed a full-stack real-time analytics dashboard using React.js, Node.js, Express.js, Tailwind CSS, Axios, and Recharts. Implemented REST APIs, dynamic transaction monitoring, real-time analytics simulation, responsive user interface, loading states, error handling, and modular backend architecture. Designed the project to support future integration with AWS Kinesis, AWS Lambda, Amazon Redshift, and Auto Scaling services.
