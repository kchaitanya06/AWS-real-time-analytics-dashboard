
# Cloud-Based Data Analytics Dashboard

## Project Overview

The Cloud-Based Data Analytics Dashboard is a full-stack web application designed to provide real-time business analytics and data visualization. The system enables users to monitor key business metrics such as revenue, users, orders, and transaction activities through an interactive dashboard.

The project is developed using React.js for the frontend and Node.js with Express.js for the backend. It follows a modular architecture and simulates real-time analytics updates.

---

## Problem Statement

Organizations require real-time analytics dashboards to visualize and analyze business data efficiently. Traditional dashboards often lack scalability, real-time capabilities, and integration with multiple data sources.

## Methodology

The project follows a full-stack development approach.

### Phase 1: Frontend Development
- Created React.js application using Vite.
- Designed dashboard layout using Tailwind CSS.
- Implemented Sidebar, Navbar, Stat Cards, Revenue Chart, and Transactions Table.

### Phase 2: Backend Development
- Created Express.js backend server.
- Implemented REST APIs for analytics and transactions.
- Organized code into Routes, Controllers, and Data modules.

### Phase 3: Frontend-Backend Integration
- Integrated APIs using Axios.
- Implemented real-time data refresh.
- Added loading states and error handling.

### Phase 4: Dashboard Enhancement
- Added interactive charts using Recharts.
- Improved responsiveness and UI design.
- Added API status indicators and hover effects.
