## Components

Real-time data ingestion.

### AWS Lambda
Data transformation and processing.

### Amazon Redshift
Data warehouse for analytics storage.

### Backend API
Provides analytics data to frontend.

### React Dashboard
Displays real-time analytics and visualizations.
